# MVX Ads Master integration

Within MVX Ads Master, this Gauzy fork is exposed as **MVX Operations**.

Its responsibility is operational governance: projects, tasks, sprints, goals, time, cost, expense/income and related execution state. MVX Ads Master communicates with the real Gauzy API using a JWT issued by the running Gauzy instance and a restricted endpoint allowlist.

MVX does not replace Gauzy with synthetic local cards and does not rename internal Gauzy namespaces, persistence keys or package identities. Visible MVX branding is deliberately separated from the application domain and upstream attribution/license obligations remain intact.
